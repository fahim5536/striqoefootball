# Project Rules

1. Never redesign the UI unless I explicitly request it.
2. Treat the current UI as locked.
3. Never delete working code.
4. Never replace existing components without permission.
5. Always preserve functionality.
6. Complete unfinished systems.
7. Replace mock data with real backend logic.
8. Use PostgreSQL + Prisma.
9. Never use Firebase.
10. Use JWT Authentication.
11. Build production-quality code only.
12. Keep code modular and reusable.
13. Write clean TypeScript.
14. Optimize performance.
15. Optimize security.
16. Test every feature before considering it complete.
17. Explain every major change before implementing it.
18. Wait for my approval before making UI changes.

# Environment
- DO NOT DELETE the `.env` file. It contains all API keys.
