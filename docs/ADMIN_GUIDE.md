# STRIQO Admin Guide

## Accessing the Admin Panel
1. Log in with an account that has the \`ADMIN\` or \`MODERATOR\` role.
2. Navigate to \`/admin\`. You will be prompted for an additional security PIN (default during alpha: \`admin\`).

## Dashboards & Analytics
- **Dashboard**: High-level overview of total active tournaments, pending matches, and disputes.
- **Analytics**: Detailed view of User Growth (MAU/DAU), AI feature usage, and tournament completion rates.
- **Reports**: Export comprehensive CSV data for a selected period (7d, 30d, 90d).

## Management
- **Tournaments**: Approve, reject, or forcefully conclude tournaments.
- **Matches**: Oversee match disputes, review AI recommendations, and override scores.
- **Users & Bans**: Role assignment, player suspension, and IP-level bans.

## System Monitoring
- **Metrics**: Track API latency, database health, and memory usage in real-time.
- **Logs**: Detailed Security Operations Center (SOC) logs tracking every sensitive admin action.
- **Feature Flags & Remote Config**: Enable or disable features remotely without redeploying.
